## ⚡ Featured Projects

### 🔌 [AMBA APB to UART Controller](https://github.com/Ashika005/AMBA-APB-UART-Controller)
> **Verilog | Icarus Verilog | GTKWave**
* Designed an industry-standard bidirectional IP block linking a high-speed parallel memory bus to a slow serial peripheral.
* Features configurable baud rates and **double-flop RX synchronization** to safely handle real-world asynchronous signals.
* Fully verified via GTKWave simulation, proving memory-mapped register writes and accurate bit-shifting logic.

### 🧠 [MIPS32 Subset Processor Design](https://github.com/Ashika005/Processor-Design-MIPS32-Subset-Verilog)
> **Verilog | Computer Architecture | RTL Design**
* Implemented a custom, single-cycle MIPS32 processor subset in Verilog.
* Architected the ALU, Register File, Instruction Memory, and Data Memory modules from the ground up.
* Modeled the complete instruction fetch, decode, and execute cycle directly in RTL.
